# 一、软件介绍

## 1.1 软件概述

**WordCraft** 是 ArtCraft 团队用纯 Rust 从零实现的开源文字处理器，目标是对标 Microsoft Word
的核心工作流：Word 风格的 ribbon 界面、字符/段落/表格样式、修订与批注、题注与交叉引用、
邮件合并。它以 `.docx`（ECMA-376 OOXML）为主格式双向读写，可导入 `.doc/.odt/.rtf/.html/
.md/.tex/.txt`，并导出**真实可选中文本**的 PDF。同一份代码原生运行于 macOS / Windows / Linux
/ FreeBSD，并编译到 WebAssembly 在浏览器中运行。

- 许可证：MIT OR Apache-2.0 双许可
- 语言：纯 Rust（约 10 万行，无 Electron、无 WebView）
- 版本：v0.5.0（alpha，上游）；本实践维护后 v0.6.0
- 规模：460 条命令，Word ribbon 功能覆盖率 ≥90.4%（内置 parity 自检）

## 1.2 主要功能

| 类别 | 代表功能 |
|---|---|
| 编辑 | 富文本段落/字符样式、查找替换、撤销/重做、多级撤销一步成型、特殊粘贴 |
| 对象 | 表格（绘制/公式/行拆分）、图片、形状、页眉页脚、脚注尾注、文本框、公式（OMML/LaTeX 输入）、墨迹 |
| 审阅 | 修订（Track Changes）、批注与回复、拼写/语法检查、朗读（Read Aloud） |
| 引用 | 目录、题注、交叉引用、Zotero 文献集成（线协议直连） |
| 邮件 | 邮件合并（SKIPIF/NEXT/IF 字段、预览） |
| 输出 | PDF 导出（子集化字体、Tagged PDF）、打印、全格式互转 |
| 自动化 | 每个功能都是一条命令：MCP 服务器（16 工具）、JSON 控制端口、CLI 无头运行 |

## 1.3 编译

依赖只有 Rust 工具链（rustup，stable ≥1.90）：

```sh
git clone https://github.com/Guiyuan1111/wordcraft.git
cd wordcraft
cargo build --release                 # 全工作区（桌面 + CLI）
cargo build --release -p wordcraft    # 仅桌面应用
cargo build --release -p wordcraft-cli  # 仅命令行
cargo test                            # 全部测试
cargo xtask layers                    # 分层规则检查（CI 同款）
```

Windows GNU 工具链注意事项（本实践踩坑记录）：中文路径会使 mingw ld 失败，需
`CARGO_TARGET_DIR` 指向 ASCII 路径；rustup minimal profile 缺 `dlltool.exe`/`as.exe`，
需补 w64devkit 或完整 MinGW 并加入 PATH。

## 1.4 安装与运行

无安装步骤，编译产物即开即用：

```sh
cargo run --release -p wordcraft                 # 桌面应用（Word 风格 ribbon 界面）
wordcraft --sample                               # 打开内置示例文档
wordcraft-cli convert in.docx out.pdf            # 格式转换
wordcraft-cli info file.docx                     # 元信息（JSON）
wordcraft-cli insights file.docx                 # 0.6.0 新增：可读性与写作质量报告
wordcraft-cli run --cmd 'text.insert={"text":"hi"}' --save out.docx   # 无头批处理
wordcraft mcp                                    # MCP 服务器（供大模型代理调用）
```

WebAssembly 版：`cargo xtask web` 后用任意静态服务器托管 `web/` 目录即可。
