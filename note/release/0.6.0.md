# 0.6.0 — Writing Insights（写作洞察）

新增面向写作者的文档质量分析子系统，纯本地统计、无网络依赖。

## 新功能

- **wordcraft-insights crate（L2）**：文本统计（拉丁/CJK 混排分词、音节、分句）、六个经典可读性指标（Flesch、Flesch-Kincaid、Gunning Fog、SMOG、Coleman-Liau、ARI）、六类写作问题检测（长句、被动语态、冗余短语、填充副词、连续重复词、句首重复）。
- **`review.insights` 命令**：纯命令（不进撤销栈），返回报告 JSON，每个 finding 附 `pos{story,path,off}` 跳转位置；MCP 自动暴露。
- **桌面端 Writing Insights 面板**：Review › Proofing › Writing Insights 打开；文档概要、可读性评级、句长直方图、最长句与问题列表点击即跳转原文；报告按文档版本缓存，文档变更才重算。
- **CLI**：`wordcraft-cli insights <file> [--json] [--notes]` 输出文本或 JSON 报告。
- **CJK 适配**：按字符计量中文句长；拉丁公式对 CJK 主导文本返回空而非给出误导性等级。

## 修复

- 剪贴板图片文件识别在 Windows 误判根相对路径（`is_absolute` 在 Windows 要求盘符）：补 `has_root()` 判定，修复上游 `paste_inserts_clipboard_pixels` 测试在 Windows 上失败。
